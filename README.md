# Movie Web Frontend
Made this website with the help of mentors in my internship with Bewise. With the integration of ReactJS + TS, JSON server, Axios, Tanstack Router + Query and SOLID principles.

## Features
- List of movies saved in TMDB 
- CRUD of local movies.
- Searchbar + Filtering + Ordering (A to Z, Z to A) 
- Add movies as favourites // Needs polishing
- Views: Home | Favorites | Add Movies | Edit Movies 

## Instalation

1. Clone this repo `https://github.com/SupySopu/MovieWeb.git`
2. Run these commands:
```bash
cd /MovieWeb
npm i
npm run dev
```
in another console
```bash
npm run server
```
3. Open browser at `https://localhost:[no me acuerdo lmao]` for the local database. 
4. (Optional) In case you want to see the local database JSON. Open browser at `https://localhost:[no me acuerdo x2]`


## Detailed Information about the Tools used

| Tool             | Reason   |
| :-:|--|
| ReactJS| Perfect for reusable components |
| TypeScript| Used to maintain order with the implementation of types and interfaces and to optimize workflow|
| JSON Server | Library to create local APIs, in this case, so that the local user can create their own movies and have them  |
| Axios | Managed services and fetching data between the local and TMDB APIs. |
| SASS | Modules helps for good organization |
| TanStack Router | Easy to use and configure files as routes |
| TanStack Query | Helps with pagination |
| Formik | Already made structure for forms |
| Headless UI | Components without styles |
